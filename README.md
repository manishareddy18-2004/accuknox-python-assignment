# AccuKnox Python Assignment

## Task 1: Books API
Fetch book information from a REST API, store it in SQLite,
and display the retrieved records.

## Task 2: Student Scores API
Fetch student scores from an API, calculate average scores,
and visualize the results using a bar chart.

## Task 3: CSV to SQLite
Read user information from a CSV file, insert the records
into an SQLite database, and display the stored data.
